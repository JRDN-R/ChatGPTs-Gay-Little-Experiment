My logo works?

For the most faithful clipboard test: tap Select full line, then use iOS's native Copy menu.

  1. Open this page in Safari on the iPhone.
  2. Tap Select full line, then choose Copy from the iOS selection menu. If unavailable, try the two copy buttons.
  3. Open a conversation in Messages, long-press its text field, tap Paste.
  4. See whether the face behaves like a small inline emoji, a regular photo, text-only, or disappears.

A button reporting “copied” only means a clipboard operation was attempted or accepted. It does not verify that Messages received a native adaptive glyph.

What would count as success?

The face appears as one inline graphic inside the Messages text bubble and remains visible when received by another compatible iPhone. This would be richer than a plain-text Unicode character, and other apps may still paste only a fallback image or description.

Apple documents reading and preserving existing NSAdaptiveImageGlyph values. A developer experiment suggests HEIC + metadata can be recognized by the text system. Copying a hand-authored WebKit picture element into Messages is unproven. If this browser route fails, a signed native iPhone app using Apple's text APIs is the next test.
